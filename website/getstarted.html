Three steps, tiny code

From empty folder to running program in about a minute.

1

Install the interpreter

Grab the runtime for your OS from the download page, or pull it straight from PyPI:

$ pip install vulpin
2

Write a .vul file

Create hello.vul in any folder. Every line is one command.

G "Hello World!"
3

Run it

Feed the file to the interpreter and watch it print.

$ vulpin hello.vul
Hello World!
