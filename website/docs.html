The command sheet

Every order on the menu, straight from the interpreter.

G / P — output

G prints a value with a newline. P prints without one. Math works too.

G"Hello" # prints with newline P"Loading..." # prints without newline G 5 + 3 # prints 8

K — typed input

Read input straight into a variable. The trailing type letter decides what counts as valid.

K user "Your name: " K age "Age: " I # integer, default 0 K price "Price: " F # float, default 0.0 K letter "Guess: " L # single char

Iint Ffloat Nnumber Lletter Wword Elower Uupper Aletters+spaces Palnum+spaces

= — variables

Assign with =, add to in place with A, replace substrings with S, delete with D.

name="Vul" A"x"+5 # x = x + 5 S"msg""o""0" # replace "o" with "0" D"y" # delete y

String shortcuts: .U upper · .L lower · .S strip · .T title · .C capitalize

? : ; — if / else

Test a condition, branch, and close the block.

? score >= 90 G"A" : ? score >= 80 G"B" : G"C" ;

@ & — while loop

@ opens the loop, & closes it. @1 loops forever.

i=0 @ i < 5 G i i=i+1 & @1 # infinite loop G"Running..." &

O — for-range

Iterate a variable over a start, end and step.

O i 0 5 # 0,1,2,3,4 G i & O x 10 0 -2 # 10,8,6,4,2 G x &

J / L — jumps & labels

J jumps to a label defined by L — with or without a condition.

J end G"Skipped" L end G"Done"

W V N Z — switch / case

Match one value against many. N starts the default case, Z closes the switch.

W fruit V"banana" G"yellow" V"apple" G"red or green" N G"unknown" Z

F R ~ — functions

Define with F, return with R, close with ~.

F add(a, b) R a + b ~ G add(3, 4) # 7 F greet(name) G"Hello " + name ~ greet("World")

U — imports

Pull in C or Vulpin modules with U, then use them with the dot operator.

U"os" G os.getcwd() os.system("echo Hello") U"math" G math.sqrt(16)

T C Y — error handling

Wrap a fragile block in T, catch with C"err", close with Y.

T x=10 y=0 G x/y # division by zero! C"err" G"Error: " + err Y G"Continues..."

D — delay

Pause for a number of seconds, or for the value stored in a variable.

D1 # wait 1 second D0.5 # wait half a second D delay # wait variable

$ — the runtime

Run, build and check the version from the terminal.

vulpin hello.vul # run a program vulpin build # build your app vulpin version # → Vul 0.9

Spaces are optional after commands — G"Hi" and G "Hi" both work.
