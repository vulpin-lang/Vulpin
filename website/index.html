Discover

Click on setup file. which allows you to install vulpin on your system.

Take a look at Docs folder to learn how to use vulpin. But you should allow to install docs in installer! because Docs is un-necessery folder, but we recommond to beginners to installing them.

Notice: After Installing Vulpin, you'll lose this file and some files that is really un-usable.

Setting up IDE

We recommend you, if you want to install vulpin, you should have IDE, to write codes easier, we recommend you to install "Vulide" that is vulpin official IDE.
